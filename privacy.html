Privacy Policy

Econ Calendar Sync is a personal script run by its owner on their own computer.

Data accessed: with the owner's consent, it uses the Google Calendar API to create, update and delete economic-release events in the owner's own "Econ" calendar.

Storage and sharing: the Google access token is stored only on the owner's computer. No Google user data is collected, sold or shared with anyone.
